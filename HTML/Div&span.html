Div Tag

Div is a container used for other HTML elements.

Block Element: Takes full width of the page.

List : Div Tag

HTML Elements inside a Div:

  • Heading
  • Paragraph
  • Image
  • Link
  • List

Span Tag

Span is also a container used for other HTML elements.

Inline Element: Takes only as much width as required.
